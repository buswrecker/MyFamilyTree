### Getting Started
There is a quite a number of free Archival / Genealogy software available to view the family tree. I've used the following

- Ancestral Quest - Download [Here](https://www.ancquest.com/download.htm)
- *Personal Ancestry File (PAF) - Obsolete* - Download [Here](http://parowansoftware.com/PAF5EnglishSetup.exe)

Import the `*.aq` file in the FamilyTree Folder into the software. If you're not using Ancestral Quest, use the generic GEDCOM file format.
